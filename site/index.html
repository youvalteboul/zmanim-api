Trois façons de l'utiliser

Le même code partout, sans aucune dépendance. Les calculs se font sur place : pas de clé, pas de quota, et la version navigateur marche hors ligne.

Node

Dans votre programme

Un module à importer, une fonction à appeler.

const API = require('zmanim-api');
const r = API.horaires({
  lieu: 'Strasbourg',
  jours: 7,
  minhag: 'standard'
});
r.jours[0].zmanim.shqia // "HH:MM"
Navigateur

Dans une page web

Un seul script de 80 ko, sans serveur ni connexion.

<script src="zmanim-api.js"></script>
<script>
const j = ZmanimAPI.horaires({
  lieu: 'Jerusalem', langue: 'he'
}).jours[0];
</script>
HTTP

Depuis n'importe quel langage

npm start lance l'API et ce site. Réponses JSON, CORS ouvert.

# GET : options en paramètres
curl 'localhost:3000/horaires?lieu=Lyon&format=iso'

# POST : offices et zmanim ajoutés
curl -d '{"lieu":"Lyon","offices":[…]}' \
  localhost:3000/horaires

Réglable avis par avis

Partez d'un minhag, puis remplacez ce que votre communauté fait autrement. La réponse rappelle toujours les avis appliqués.

CodeSens
16.1Soleil à 16,1° sous l'horizon. N'importe quel angle : 18, 12.5…
72p72 minutes proportionnelles (heure GR"A divisée par 60) avant le netz ou après la shqi'a.
45f45 minutes fixes, quelle que soit la saison.
ajoutsVos propres zmanim : décalage depuis un zman, ou angle du soleil, avec arrondi aux 5 ou 10 minutes.
officesHeure fixe, ou relative à un zman (« Min'ha 15 min avant la shqi'a, arrondie aux 5 min »).
